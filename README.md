# BLACK STORE — Landing Page Premium

Landing page demonstrativa conceitual para a **BLACK STORE**, desenvolvida sob o conceito visual **BLACK LUXURY STREETWEAR**, unindo moda masculina contemporânea, estética editorial e foco em conversão comercial via WhatsApp e visitas à loja física.

## 🚀 Tecnologias

- **Next.js 15 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS v3**
- **Lucide Icons**
- **Google Fonts (Manrope & Oswald)**

## 📱 Recursos & Funcionalidades

- **Identidade Preservada:** Logotipo original em alta resolução.
- **Hero Editorial:** Primeira dobra cinematográfica com foco em contraste e legibilidade.
- **Categorias Dinâmicas:** 6 categorias principais (Tênis, Camisetas, Esportivo, Bermudas, Moletons, Casual & Social) integradas à vitrine.
- **Vitrine Filtrável:** Catálogo demonstrativo com filtros reativos e tags de destaque.
- **Integração WhatsApp:** Mensagens personalizadas e codificadas por produto (*"Olá! Vi o produto [X] no site..."*).
- **Linha Esportiva:** Seção editorial com layout assimétrico dedicada ao futebol e ao streetwear esportivo.
- **Espaço Físico & Horários:** Exibição clara dos horários de atendimento identificados nos canais oficiais.
- **Responsividade Total:** Menu gaveta mobile com bloqueio de scroll e foco acessível.
- **Acessibilidade:** Suporte a `prefers-reduced-motion` e navegação semântica.

## 💻 Como Rodar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

Para compilar e rodar a versão de produção:

```bash
npm run build
npm run start
```
